# Global YouTube Analysis Dashboard

## Description
This project presents an interactive Tableau dashboard for analyzing global YouTube data. The dashboard is designed to visualize key patterns and comparisons in YouTube-related metrics.

## Objective
The objective of this project is to explore global YouTube data and present the insights through an interactive dashboard.

## Dashboard
You can view the interactive dashboard here:

[View Dashboard on Tableau Public](https://public.tableau.com/app/profile/hesty.rahmayanti/viz/GlobalYouTubeAnalysis/Dashboard2)

## Dataset
The dataset used in this project is included in the `data/` folder.

## Tools
- Tableau Public
- Excel/CSV
- Data Visualization

## Files
- `data/` contains the dataset used in the analysis.
- `images/` contains dashboard preview images.
- `tableau/` contains the Tableau workbook file.
- `README.md` contains the project documentation.

## Key Insights
- The dashboard shows an overview of global YouTube data.
- The visualization helps compare YouTube-related metrics across categories or regions.
- Interactive filters allow users to explore the data more easily.
